## Criterios de documentación

- **ID**: identificador interno estable del indicador o dataset.
- **Indicador**: nombre corto y legible.
- **Descripción**: definición económica o estadística.
- **Fuente**: entidad oficial responsable.
- **Dataset/serie**: nombre o código de la serie/dataset en la fuente.
- **Frecuencia**: diaria, mensual, trimestral, anual u otra.
- **Unidad**: pesos, índice, porcentaje, personas, etc.
- **Fecha inicial / final**: cobertura temporal conocida.
- **Metodología**: referencia a notas metodológicas relevantes.
- **URL**: enlace oficial de consulta o descarga.
- **Método de extracción**: mecanismo previsto o implementado para obtener los datos.
- **Observaciones**: notas de calidad, revisiones, rupturas metodológicas o advertencias de uso.
